Section 5
Modes
Everything Refract does is gated by a class on the body element. There is no other switch. Eight accents times two colour schemes is sixteen combinations, and lite doubles it again.
The body-class contract
stash-liquid-glass
The theme is on. Every selector in every sheet starts here.
refract-<hue>
Accent preset: blue, pink, red, yellow, purple, green, teal. Orange is the unclassed default.
refract-light
Light mode. Redefines the colour and shadow tokens in one scope.
refract-lite
Performance mode. Loaded last, wins everything.
refract-flourish-tiers
Extravagant rating style. The tier frames only apply here.
refract-minimal-cards
Minimal rating style. An accent halo scaled by score, nothing more.
refract-perf-layout-card
Playing-card performer layout.
refract-rating-system-stars
Stash is set to STARS, not DECIMAL. Auto-detected, no setting.
refract-sc-* / refract-pc-*
Per-element card visibility, derived from the CARD_ELEMS table.
stash-route-<path>
The current route. Added by JS at boot, so it does not exist on first paint.

Lite is not the theme with the fun removed.
It is the theme on a machine that cannot composite. Anything that becomes unreadable in lite is a bug, not a trade-off. Note that 0.06 alpha without blur reads as a film over scrolling content, which is why the floating surfaces go opaque rather than staying faint.
Route classes flash.
They are added by JS at boot, so anything gated on one is unstyled on first paint. If an element is flash-prone, hide it with an unscoped rule as well. Visibility toggles double their gate class for specificity; the country gate triples it, because playing-card's country-with-rank rule ties a double.
